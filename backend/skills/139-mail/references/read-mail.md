# 读信

## 何时使用

用户要看某封邮件详情、正文、附件名单，或要总结、提取待办之前，必须先读信。

## 怎么用

```bash
python scripts/read_mail.py <mid>
```

`mid` 来自搜索/草稿列表对应序号，不要向用户展示。用户说「第 2 封」或报主题时，在本轮列表里解析后再调用。

## 怎么回复

用脚本返回的发件人、收件人、主题、时间、正文组织自然语言。附件只列文件名和大致大小，不自动下载。

总结或提取待办必须基于返回的 `content`，不要只用搜索列表里的摘要。详见 [mail-summary.md](mail-summary.md)、[todo-from-mail.md](todo-from-mail.md)。
